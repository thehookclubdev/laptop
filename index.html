Laptop

Set up a fresh Mac for Hook Club development in one command.

Paste this into Terminal:

curl -fsSL https://dev.thehookclub.nyc/install.sh | bash

You'll be asked for your macOS password once. It's safe to re-run — every step checks before it acts. Clones itself to ~/thc/laptop.

What it installs

  • mise — provisions Node (latest LTS)
  • direnv — loads each repo's .envrc (GitHub Packages token from 1Password)
  • gh — GitHub CLI
  • starship — shell prompt
  • redis, libpq — local Redis for the admin app / Postgres client tools
  • netlify-cli — deploys the Netlify-hosted apps
  • orbstack — Docker engine
  • ffmpeg, yt-dlp — song reference downloads
  • 1Password + op — secrets & SSH
  • Claude Code — Anthropic's CLI
  • zed, linear, tableplus, ghostty, rectangle

It also wires mise, starship, and direnv into ~/.zshrc, provisions Node, starts Redis, and points ~/.ssh/config at the 1Password SSH agent.

After it finishes

Secrets come from the Hook Club 1Password — nothing is pasted or stored on disk. You need access to the shared developer vault (an admin adds you). In the 1Password app, enable Settings → Developer → Integrate with 1Password CLI, Use the SSH agent, and Touch ID. Then sign in, pull the repos into ~/thc, and give each one its .envrc:

op signin
op document get workspace --vault developer | bash
~/thc/laptop/envrc
